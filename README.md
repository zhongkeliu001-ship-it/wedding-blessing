# 吾师有喜 · 婚礼祝福页

为老师李成龙与朱彩奕制作的学生祝福页面。页面为纯静态文件，样式和交互内嵌于 `index.html`，不依赖外部字体、脚本或图片服务。

## 本地预览

在本目录启动静态文件服务器：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 文件

- `index.html`：页面、样式与交互
- `assets/`：婚礼照片与视频
- `.nojekyll`：让 GitHub Pages 直接发布静态文件

婚礼日期、地点、席设、落款学生姓名和二维码位置仍待补充。
